# Python 基础练习示例

## Python 基础题库
- 题库编码: python_basics_bank

### python_basics_bank_q001
- **题型**: 单选题
- **题干**: Python 中，哪一种内置类型是可变的有序集合？
- **选项**:
A. list
B. tuple
C. int
D. bool
- **答案**: A
- **解析**: list 是可变的有序集合；tuple 是不可变序列。
- **知识点**: 列表, 元组

### python_basics_bank_q002
- **题型**: 简答题
- **题干**: Python 中 break 和 continue 有什么区别？
- **答案**: break 结束当前循环；continue 跳过当前迭代剩余语句，进入下一次迭代。
- **解析**: 二者作用于当前所在的循环，不能混为退出函数。
- **知识点**: 循环, 控制流

### python_basics_bank_q003
- **题型**: 简答题
- **题干**: Python 中可变默认参数为什么可能导致多次函数调用共享状态？
- **答案**: 默认参数在函数定义时求值；可变对象被后续调用复用。
- **解析**: 可使用 None 作为默认值，并在函数体内创建新的列表或字典。
- **知识点**: 函数, 默认参数
