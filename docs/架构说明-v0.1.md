## 运行与数据

FastAPI lifespan 创建基础服务客户端、本地模型、LLM 客户端和业务服务。启动时初始化业务索引与对象桶，结束时先停止任务，再释放模型、HTTP 连接和基础服务资源。基础配置不完整时页面和健康检查仍可访问，相关业务返回明确错误。

MongoDB 保存课程、题库、文档、版本、任务、章节、切片、聊天和引用快照；Milvus 保存 BGE-M3 稠密及学习型稀疏向量；MinIO 保存原件和标准文本。`output/` 是本地检查、评测及临时产物目录，不是正式业务存储。

当前固定使用一个 Uvicorn worker。导入采用有界队列和单消费者，本地模型通过线程池及信号量限制并发；同一会话只能有一个问答请求。重启会将未完成导入标记为 interrupted，将未完成消息标记为 cancelled，需手动重试。

## 资料导入

上传与校验 → 原件和版本记录 → 解析与标准文本 → 切片及索引 → 校验后激活版本。

- 文件类型、大小、DOCX 解压大小和归属在服务端校验。未归属文件先保存原件，指定课程或项目后建立索引。
- Markdown 使用 CommonMark token 解析标题及源行号；DOCX 按段落与表格块顺序提取，支持标题大纲和样式映射。切片使用实际 Embedding tokenizer，保留章节和源位置。
- 课程目录交由配置的 LLM 识别系列及课程，程序校验名称、编码和原文行号。不确定结果等待人工确认，旧活动目录继续可用。
- 结构化题库使用专门的 Markdown 解析器；导入成功仍标记未审核。练习列表不返回答案，用户主动查看解析时读取答案。
- 相同来源、归属、内容与处理配置复用已有任务；更新成功才切换活动版本，失败保留旧版。删除先撤销检索资格，再清理索引和原件。

## 检索问答

请求与会话校验 → 意图路由 → 结构化查询或资料检索 → 证据回答 → 引用校验 → 保存结果。

课程浏览、选课引导、练习查询和答案查看有各自的受控分支。资料答疑使用 BGE-M3 稠密与学习型稀疏召回，做一次 RRF 融合后重排，并过滤已删除或非活动版本的内容。稀疏向量不是 BM25。

普通接口返回最终结果。SSE 生成通过模型 `astream` 返回回答增量，前端显示为引用待核对的草稿；`done` 返回引用校验后的最终结果。校验不通过时显示资料不足，草稿不写入历史。连接断开或取消时清除草稿并取消消息。

## 当前边界

- 单机、单用户；没有登录、角色权限和按用户隔离，默认监听本机地址。
- 文档解析不提供 DOCX 原始页码，不提取图片、页眉页脚、文本框或嵌套表格；不支持 PDF 与 OCR。
- 无联网检索或自主工具规划。前端文学短句有单独的一言网络请求，失败后保留默认文案。
- 健康检查不调用付费生成接口；LLM 配置就绪不代表供应商连通或回答质量已经验证。
- 自动回归测试使用隔离存储和模型替身；目标机器的真实服务、GPU、LLM 及资料效果需要另行验证，自动引用格式检查不等于人工语义审核。
