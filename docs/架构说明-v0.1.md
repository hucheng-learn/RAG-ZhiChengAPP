# 知成：架构说明

适用版本：0.1.0；核对日期：2026-10-20。本文描述当前源码；[登录与用户权限设计](登录与用户权限设计-v0.1.md) 是尚未实现的后续方案。

## 目录职责

| 目录 / 文件 | 职责 |
| --- | --- |
| `app.py` | FastAPI 应用工厂、生命周期、路由、request_id 中间件、静态页面和错误处理 |
| `api/`、`schemas/` | HTTP 接口及请求、响应和业务数据模型 |
| `services/` | 课程查询、选课引导、导入、版本管理、检索问答、语音识别与运行时协调 |
| `processor/` | LangGraph 导入与查询工作流及状态定义 |
| `repositories/` | MongoDB 访问、集合白名单与索引初始化 |
| `utils/parsers/`、`utils/chunking/` | Markdown / DOCX / 目录 / 题库解析、图片引用识别与 tokenizer 预算切片 |
| `utils/clients/`、`utils/llm/` | MongoDB、Milvus、MinIO、MinerU、Embedding、Reranker 和 LLM 适配；`infrastructure.py` 统一管理基础服务连接与共享超时 |
| `common/` | 配置（`config/`）、日志（`logging/`）与业务错误 |
| `page/` | 同源 HTML / CSS / JavaScript 界面，无前端构建步骤；含语音录制与回答图片展示脚本 |
| `deploy/`、`scripts/` | 基础服务 Compose、配置、检查、导入、评测与打包工具 |
| `tests/` | 组件测试、接口流程测试、前端 Node 测试与示例资料；评测脚本见 `scripts/` |

## 运行与数据

FastAPI lifespan 创建基础服务客户端、本地模型、LLM 客户端和业务服务；语音识别客户端在应用工厂中创建，复用 LLM 密钥。启动时初始化业务索引与对象桶，结束时先停止任务，再释放模型、HTTP 连接和基础服务资源。基础配置不完整时页面和健康检查仍可访问，相关业务返回明确错误。

MongoDB 保存课程、题库、文档、版本、任务、章节、切片、聊天和引用快照；Milvus 保存 BGE-M3 稠密及学习型稀疏向量；MinIO 保存原件和标准文本。`output/` 是本地检查、评测及临时产物目录，不是正式业务存储。

日志同时输出到控制台和项目根目录 `logs/zhichengapp.log`（按大小轮转），记录请求方法、路径、状态码、耗时及 `request_id`；请求日志不含查询参数、请求正文或请求头。

当前固定使用一个 Uvicorn worker。导入采用有界队列和单消费者，本地模型通过线程池及信号量限制并发；同一会话只能有一个问答请求。重启会将未完成导入标记为 interrupted，将未完成消息标记为 cancelled，需手动重试。

## 资料导入

上传与校验 → 原件和版本记录 → 解析与标准文本 → 切片及索引 → 校验后激活版本。

- 文件类型、单文件与单批大小、DOCX 解压大小和归属在服务端校验。未归属文件先保存原件，指定课程或项目后建立索引。
- Markdown / TXT 本地解析；DOCX 按段落与表格块顺序提取，支持标题大纲和样式映射，并保留内嵌图片（图片文字不参与检索，页面显示警告）。配置 `ZHICHENGAPP_MINERU_API_TOKEN` 后，DOCX、PDF、DOC、PPT/PPTX 和常见图片改用 MinerU v4 解析并 OCR，解析结果标注“解析后文本”行号。切片使用实际 Embedding tokenizer，保留章节和源位置。
- 课程目录交由配置的 LLM 识别系列及课程，程序校验名称、编码和原文行号。不确定结果等待人工确认，旧活动目录继续可用。
- 结构化题库使用专门的 Markdown 解析器；导入成功仍标记未审核。练习列表不返回答案，用户主动查看解析时读取答案。
- 相同来源、归属、内容与处理配置复用已有任务；更新成功才切换活动版本，失败保留旧版。删除先撤销检索资格，再清理索引和原件。
- 文件夹导入保留来源相对路径，Markdown 图片按相对路径匹配后随所属文件作为附件提交；被引用图片不单独建任务。

## 检索问答

请求与会话校验 → 意图路由 → 结构化查询或资料检索 → 证据回答 → 引用校验 → 保存结果。

课程浏览、选课引导、练习查询和答案查看有各自的受控分支。资料答疑使用 BGE-M3 稠密与学习型稀疏召回，做一次 RRF 融合后重排，并过滤已删除或非活动版本的内容。稀疏向量不是 BM25。

普通接口返回最终结果。SSE 生成通过模型 `astream` 返回回答增量，前端显示为引用待核对的草稿；`done` 返回引用校验后的最终结果。校验不通过时显示资料不足，草稿不写入历史。连接断开或取消时清除草稿并取消消息。

聊天语音输入把录音经后端转发给阿里云语音识别接口，音频仅在内存中处理；未配置 `ZHICHENGAPP_ASR_MODEL` 时该能力不可用，`/api/v1/capabilities` 会如实上报。

## 当前边界

- 单机、单用户；没有登录、角色权限和按用户隔离，默认监听本机地址。
- 未配置 MinerU 时不支持 PDF / 图片 OCR；本地 DOCX 解析不提供原始页码，不提取页眉页脚、文本框或嵌套表格。解析后文本的行号与原件页码不同，引用明确标注来源。
- 无联网知识检索或自主工具规划。前端文学短句有单独的一言网络请求，失败后保留默认文案。
- 健康检查不调用付费生成接口；LLM 配置就绪不代表供应商连通或回答质量已经验证。
- 自动回归测试使用隔离存储和模型替身；目标机器的真实服务、GPU、LLM、MinerU 及资料效果需要另行验证，自动引用格式检查不等于人工语义审核。
